# Tutor

Script-verbatim AI classroom: you write 1–20 lines, the tutor speaks those lines exactly, Groq draws blackboard notes/diagrams, and Simli lip-syncs the face to the same audio.

## Overview

Tutor is a virtual classroom. Speech is **never** generated by the LLM. The LLM’s only job is presentable notes and diagrams on an Excalidraw blackboard, animated while Edge TTS (and Simli) play the script.

## Features

- Paste 1–20 script lines; TTS repeats them verbatim
- Groq (or local fallback) draws related notes, flowcharts, and graphs
- Notes animate in sync with each spoken line
- Simli avatar lip-syncs to Edge TTS audio
- Providers swapped from `.env` (LLM / TTS / STT / avatar)
- Optional mic → script box (Groq Whisper or browser STT)

## Architecture

Lean C4 + sequence docs live in [`docs/`](docs/README.md). Short version: browser → FastAPI modular monolith → Groq / Edge TTS / Simli.

## Tech Stack

| Layer | Choice |
|---|---|
| Frontend | React, Vite, Excalidraw |
| Backend | Python FastAPI |
| LLM notes | Groq (`openai/gpt-oss-20b`), local diagram fallback |
| TTS | Microsoft Edge neural voices |
| Avatar | Simli WebRTC |
| STT | Groq Whisper, browser fallback |

## Prerequisites

- Python 3.11+
- Node.js 20+
- Optional: `GROQ_API_KEY`, `SIMLI_API_KEY`, `SIMLI_FACE_ID`

## Local Setup

See [docs/development.md](docs/development.md). Quick path:

```bash
python -m pip install -r backend/requirements.txt
python -m pip install -r backend/requirements-dev.txt
npm install
npm --prefix frontend install
copy .env.example .env   # Windows
# then fill keys in .env — never commit .env
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173). API: [http://127.0.0.1:8787](http://127.0.0.1:8787). Health: `/health`. OpenAPI: `/docs`.

## Known Limitations

- Speech is script-verbatim by design; the LLM cannot ad-lib a lecture
- Without `GROQ_API_KEY`, notes use a local diagram heuristic
- Simli needs a valid face id and remaining minutes
- No user accounts, persistence, or multi-tenant auth
- Local diagram fallback when Groq is unavailable
